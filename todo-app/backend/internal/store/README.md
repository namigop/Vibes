# internal/store

This directory is generated by `sqlc`. **Do not hand-write the `*.sql.go`
or `*.go` files** here; they will be overwritten every time `sqlc generate`
runs.

## Generating

From `backend/`:

```sh
# One-time install (any platform with Go):
go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest

# Generate:
sqlc generate
# or
make generate
```

After generation the directory will contain:

- `db.go`            – `New(pool) *Queries`, the entrypoint used by `cmd/server/main.go`
- `models.go`        – struct definitions (`Todo`, etc.) with JSON tags
- `queries.sql.go`   – the typed methods (`ListTodos`, `GetTodo`, `CreateTodo`, …)

If you cannot run sqlc on this machine, generate from inside the running
backend dev container instead:

```sh
docker compose run --rm backend sqlc generate
```
